SHAFRITHAJ FATHIMA — PORTFOLIO
================================

FOLDER STRUCTURE:
  index.html          → Main portfolio page (open this in your browser)
  css/
    style.css         → All styles
  js/
    main.js           → Scroll reveal + nav effects
  images/
    hero.jfif         → Hero portrait (purple polo, free hair)
    about.jfif        → About section (desk, red floral kurti)
    psiog-wall.jfif   → Psiog संयोग wall photo
    psiog-team.jfif   → Psiog team office photo
    conference.jfif   → ICSETS-2025 conference / blue dress
    singing.jfif      → Classical vocalist (silk pavadai, mic)
    sastra-dance.jfif → SASTRA stage dance performance
    stage-group.jfif  → Sparkle stage group
    studio.jfif       → Dance studio group (graffiti wall)
    brooklyn.jfif     → Brooklyn tee dance team
    family-amma.jpeg  → Amma with little brother
    family-brother.jpeg → Little brother (mosque)

HOW TO ADD MORE PHOTOS:
  Simply drop your new .jfif files into the images/ folder
  and update index.html src="images/yourfile.jfif" in the
  relevant section.

HOW TO OPEN:
  Open index.html directly in any browser (Chrome, Edge, Firefox).
  All files must stay in the same folder structure.
